# Cafe Addon

Cafe **2.11.0** adds coffee cherries, coffee roasting, tea processing, oat milk, espresso drinks, cocoa, boba, iced coffee, and the Barista Machine. Install the matching **Heirloom Core 2.11.0** update. See [Installation](../../getting-started/installation.md) for Paper, Java and licensing requirements.

Cafe content registers into the normal Heirloom recipe browser, but the final drink assembly uses the Cafe Barista Machine.

Use `/hlc help` for addon commands.
